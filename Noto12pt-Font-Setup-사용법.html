WINDOWS 10 · 글꼴 설정

글자를 크고 굵게

설정 파일 하나로 메뉴와 아이콘의 글자를 읽기 쉽게 바꿉니다. 현재 화면 배율에 맞춰 글자 크기를 계산합니다.

글자 크기 12pt 굵기 600 인터넷 불필요
시작하기

세 단계로 설정하세요

설정할 PC에서 글꼴을 사용할 계정으로 로그인한 뒤 진행합니다.

  1. 1

    설정 파일을 PC에 복사합니다

    Noto12pt-Font-Setup.cmd 파일 하나만 복사하면 됩니다. 필요한 글꼴이 파일 안에 들어 있습니다.

  2. 2

    파일을 더블클릭합니다

    처음 글꼴을 설치할 때 관리자 권한 확인 창이 나타날 수 있습니다. 확인 후 작업이 진행됩니다.

  3. 3

    완료 메시지를 확인합니다

    검은 창에 Windows 글꼴과 브라우저 처리 결과가 표시됩니다. 내용을 확인한 뒤 아무 키나 누르면 창이 닫힙니다.

설정 CMD 파일 받기 이 버튼은 사용법 HTML과 CMD 파일이 같은 폴더에 있을 때 사용할 수 있습니다.
브라우저가 열려 있나요?
Chrome이나 Edge를 강제로 종료하지 않습니다. 모든 창과 프로세스가 완전히 종료되면 현재 로그인 중에 자동으로 기본 글꼴을 적용합니다.
적용 내용

어디에 적용되나요?

  • Windows 메뉴·아이콘 등: Noto Sans KR SemiBold, 12pt, 굵기 600
  • Chrome·Edge 기본 글꼴: 한글은 Noto Sans KR, 영문·숫자는 Noto Sans SemiBold

프로그램이나 웹사이트가 자체 글꼴을 지정한 경우에는 해당 설정을 따릅니다. 실행 중인 앱은 다시 열어야 변경이 보일 수 있습니다.

화면 배율

크기는 자동 계산됩니다

화면 배율은 그대로 두고, 12pt에 맞는 글꼴 높이를 계산합니다.

시스템 화면 배율글꼴 높이 설정
100%16px
125%20px
150%24px
200%32px

여러 화면을 쓰는 경우 시스템 DPI를 기준으로 계산합니다.

되돌리기

이전 글꼴로 복원하기

  1. Chrome과 Edge를 완전히 종료합니다.
  2. CMD 파일이 있는 폴더를 열고, 파일 탐색기 주소 표시줄에 cmd를 입력한 뒤 Enter를 누릅니다.
  3. 열린 창에 아래 명령을 입력하고 Enter를 누릅니다.
Noto12pt-Font-Setup.cmd /restore

실행 전 설정으로 되돌립니다. 설치된 Noto 글꼴 파일은 다른 사용자도 사용할 수 있도록 유지됩니다.

첫 설정 전 백업은 다시 실행해도 보존됩니다. 백업 위치:

%LOCALAPPDATA%\Local-PC-Management\Noto12pt\backup

문제가 있을 때

이렇게 확인하세요

  • 변경이 보이지 않으면: 해당 프로그램을 다시 열어 확인합니다. 자체 글꼴을 쓰는 화면은 따로 설정해야 할 수 있습니다.
  • 브라우저가 열린 채 로그아웃했다면: 다시 로그인한 뒤 CMD 파일을 재실행합니다.
  • 설정 없이 파일만 확인하려면: 명령 프롬프트에서 아래 명령을 실행합니다.
Noto12pt-Font-Setup.cmd /check
Windows 10 1803·22H2에서 125%·150% 배율로 확인했습니다. 브라우저 설정은 격리된 시험 프로필로 검증했습니다.
